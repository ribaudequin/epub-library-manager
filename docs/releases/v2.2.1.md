## Chapter excerpt, now reliable

Opening a series now shows the first paragraphs of volume 01's first chapter in the detail header, read from the EPUB on demand.

### Fixed

- **`.html` documents were never read** — only `.xhtml` was considered, so volumes whose text lives in `section-*.html` returned no excerpt at all.
- **Chapter 10/12 matched "Chapter 1"** — the heuristic had no word boundary, so *Imperial Reincarnation* showed chapter 12 and *The Reincarnated Mastermind* chapter 10. A boundary is now required.
- **ZIP order instead of the OPF spine** — the first file in the archive could be the afterword (*Sentenced to Be a Hero*) or a table of contents. Reading order now follows the spine.
- **Tables of contents were returned as prose** — TOCs are rejected by filename, by `<nav epub:type="toc">`, by a "Contents" title, or by a short page made mostly of links. This covers the neutrally named `part0001.xhtml` shape used by *Berserk of Gluttony* and *Crest of the Stars*.
- **Drop caps were split** — inline tags are now removed without inserting spaces (`Youji`, not `Y ouji`), and HTML entities are decoded.

### Selection order

Explicit "Chapter 1" heading → `chapter1` file → first narrative text → prologue → author's afterword (for volumes with no narrative opener).

### Verified

- 298 series scanned, including *Berserk of Gluttony* Vol. 01 and *Crest of the Stars* Volume 1: **0 nulls, 0 tables of contents**.
- `npm test`, `npm run lint` and the new `npm run test:excerpt` (15 checks) pass.
- The local AppImage was built, inspected inside `app.asar`, and validated.
