## Notes for Japanese Translation

1. **Politeness level**: Use です/ます form (standard UI Japanese)
2. **Units**: Japanese uses counters (冊 for volumes, 回 for times, etc.) — adapt `{unit}` placeholders accordingly
3. **Date format**: `ja-JP` locale uses `YYYY/MM/DD` — the `dateTag` in registry handles this
4. **Star button**: `btn_favorite_star` / `btn_unfavorite_star` include the ★ character — keep it
5. **Placeholders**: Never translate `{count}`, `{pct}`, `{unit}`, `{filtered}`, `{total}`, `{done}`
6. **Brand terms**: Keep `EPUBShelf`, `Ko-fi`, `Patreon`, `GitHub`, `ETH`, `SOL`, `EVM` as-is
7. **Fallback chain**: ja → en → pt (configured in `SUPPORTED_LOCALES`)

---

## After Translation

1. Uncomment `ja` in `SUPPORTED_LOCALES` (line 6 of `translations.js`)
2. Paste the filled `ja: { ... }` object into `TRANSLATIONS`
3. Run `npm run i18n:validate` to verify key parity
4. Run `npm run test:excerpt`, `npm run test:cache`, etc.
5. Test with `LANG=ja_JP.UTF-8` or `--lang=ja` in Playwright
