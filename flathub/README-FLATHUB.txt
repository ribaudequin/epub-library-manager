EPUB Shelf - Flatpak Bundle

This is a manual Flatpak build of EPUB Shelf.
Since this is not a proper Flathub submission, these files
are intended for testing purposes.

For proper installation:
1. Install Flatpak on your system
2. Clone this repository
3. Run: flatpak-builder --user --install --force-clean build-dir io.github.ribaudequin.epub-library-manager.yml
4. Then: flatpak build-bundle repo BibliotecaEpub-1.8.1.flatpak io.github.ribaudequin.epub-library-manager

Alternatively, wait for official Flathub publication at:
https://flathub.org/apps/io.github.ribaudequin.epub-library-manager
